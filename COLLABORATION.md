# Collaboration Guide 🚀

Best practices for team collaboration and pair programming on open source projects.

## Pair Programming & Co-Authorship
GitHub attributes commits to multiple authors when the `Co-authored-by:` trailer is provided in the commit description.

### Example
```bash
git commit -m "feat: implement new module" -m "Co-authored-by: Collaborator <username@users.noreply.github.com>"
```
